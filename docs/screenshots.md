# 画面と機能

**やりたいことリスト100** の主な画面。実際に触れるのは **https://yaritai100list.aiandrox.workers.dev**。

仕様の意図は `PRODUCT_SPEC.md`、なぜそう決めたかは各イシューのコメントにある。
このページは「どんな画面があるか」を並べるだけで、判断は残さない。

画像はモバイル幅（390px）で撮影。ログイン状態の画面はローカルにセッションを差し込んで撮っている。

### SNS シェアのカード

<img src="./screenshots/ogp.png" width="480">

トップページを SNS に貼ったときのカード画像。番号付きの升目と打ち消し線で、文を読まなくても「たくさん書いて、叶えたら印を付けるもの」と伝わるようにしている。
個別の共有 URL には、そのリストのタイトルと達成状況（`23 / 100`）を焼いたカードが別に生成される。
