# 検索エンジン向けの指示（#229）。
#
# SPA は1枚の index.html が全ルートに出るので、
# **HTML の meta では画面ごとに出し分けられない。** ここで分ける。

User-agent: *

# 編集画面。ログインしないと中身が無く、そもそも他人は開けない
Disallow: /lists/

# API。返るのは JSON で、載っても意味がない
Disallow: /api/

# 🔴 /share/ は **Disallow しない。**
# あちらは HTML の meta に noindex が入っている（src/share.ts）。
# ここで巡回を止めると **その noindex を読んでもらえず**、
# 外からリンクされたときに URL だけが載ることがある。
# 「巡回させて、載せないでと伝える」方が確実。
